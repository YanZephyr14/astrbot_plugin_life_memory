# 仿真实生活 (Life Memory for AstrBot)

给 AI 角色一个**仿真实的生活**：每天第一次上线规划今天大致做什么（参考天气、心绪、手头的事，偶尔有突发的小事），再把「今天做过的事」和「今天的规划」每轮动态注入，让她说自己的生活时前后一致、有日常、有起伏。

当天的小事记一天，进行中的大事记到结束。

> 💡 **致谢与灵感来源**：本项目思路与设计灵感来自社区小肥鱼的 `life-memory` 插件，在此表示诚挚感谢！

---

## 它解决什么问题

想让人设里的“生活线”真正活起来，光写设定是不够的 —— 缺的是**记忆层**：

- 跨轮记忆通常只记“对用户的印象”，角色缺乏自己的生活经历；
- 角色昨天说“在等一个快递”，今天就忘了；说“稿子卡住了”，下次提起来又像没发生过；
- 结果就是生活线变成一堆**每次重新编的碎片**，没有连续性。

本插件将生活事件分成两类，分别采用不同的保留策略：

| 类型 | 保留策略 |
|---|---|
| **当天的小事**（吃了什么、去了哪、买了什么） | 记一天（默认 24 小时），再次触碰时刷新续期，隔天自动淡忘 |
| **进行中的事**（在等快递、稿子卡住、跟谁还没和好） | 跨天一直保留，直到角色主动用 `life_done` 结束；附带 7 天长兜底防僵尸挂起 |
| **每日生活规划** | 每天第一次上线规划今天大致安排，每轮注入作为日常基调 |

## 大模型工具 (LLM Tools)

插件向模型提供 4 个标准工具（装上即可用，模型会根据动态注入的引导自主调用）：

| 工具名称 | 作用 |
|---|---|
| `life_plan` | 规划今天大致做什么（支持填写大致日程、偶发突发小事、天气） |
| `life_note` | 记一条自己的生活事件；若事件“还没结束”则标记 `ongoing: true`（自动去重与合并续期） |
| `life_recall` | 回忆：进行中的事 + 近期（默认 24 小时内）的小事 |
| `life_done` | 结束一条进行中的事（按关键词匹配并收尾） |

---

## 每轮动态提示词注入 (Prompt Injection)

遵循 AstrBot 性能与 Prompt 缓存最佳实践：
- **不污染系统提示词**：不追加到 `req.system_prompt`，保护大模型服务端的 Prompt 缓存，避免 Token 费用倍增与高延迟；
- **单轮临时生效**：通过 `req.extra_user_content_parts.append(TextPart(...).mark_as_temp())` 注入临时动态上下文，不污染长期会话历史。

每轮注入内容包含：
1. **使用说明**（默认开启，装上即可生效，无需修改人设卡）；
2. **进行中的事**（最多 3 条）；
3. **今天做过的事**（最多 5 条）；
4. **今天的规划**（若今天尚未规划，则动态注入提醒引导规划）。

## 用户与管理员指令

除了供模型自主调用外，用户也可以在聊天中通过指令直接查看和管理生活记忆：

| 指令 | 说明 |
|---|---|
| `/life status` | 查看当前生活记忆状态、作用域、事件统计与今日规划 |
| `/life recall` | 手动回忆当前记录的生活事件（进行中 + 近期） |
| `/life plan <规划内容>` | 手动设定今日生活规划 |
| `/life clear` | 清空当前作用域下的所有生活数据 |

## 建议人设片段（可选）

如果你更愿意把用法直接写进**角色的人设卡 / 系统提示**（更贴合自己的角色，也省去每轮注入使用说明的 Token），可以在插件配置里将 **「自动注入使用说明」(`inject_guide`)** 关闭，然后把下面这段加进人设：

```text
【你自己的生活】
· 每天第一次上线，先用 life_plan 记下今天大致做什么（参考天气、心绪、手头的事；偶尔有突发的小事）。
· 你手头常有一两件还没完的事（在等一个快递、写的东西卡住了、跟谁还没和好），会拖好几天。
· ⚠️ 遇到"正在进行、还没结束"的事，当场用 life_note 传 ongoing=true 记下，别等、别只靠脑子记
  ——记了才跨多轮、跨天接得上；结束了用 life_done 收掉。
· 当天的小事（吃了什么、去了哪、买了什么）可以顺手记下（只记一天，隔天自动淡忘），但不必每件都记。
· 想接上"我之前在做什么/在等什么"，用 life_recall 查，别凭空猜。
· 别把机制当话题：不说"我刚记了生活事件"这类话。
```

### 生活线设定模板（照这个填，写进人设卡）

```text
【我的生活线（固定设定，别自己改）】
· 住哪：______（例：南方小城一栋老楼的顶楼，安静但没电梯）
· 在家做什么：______（例：接零散的活，作息不规律，爱睡懒觉）
· 宠物：______（例：一只挑嘴的猫，叫团子）
· 周围有谁：______（例：楼下住着个爱打听的邻居，总来串门）
· 习惯与口味：______（例：嗜甜，早餐一定要喝热豆浆）
· 常做的事：______（例：傍晚下楼走两圈，晚上刷手机）
```

## 插件配置项

| 配置键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 总开关（关掉后不再记录/规划，已存数据保留） |
| `inject_guide` | bool | `true` | 是否自动注入使用说明。人设卡已写规则的用户可关闭以节省 Token |
| `small_ttl_hours` | int | `24` | 小事保留时长（小时）。默认 24 小时，之后自动淡忘 |
| `ongoing_ttl_hours` | int | `168` | 进行中大事长兜底时长（小时）。默认 7 天（168 小时） |
| `max_events` | int | `60` | 事件池上限，防止无限膨胀 |
| `storage_scope` | string | `session` | 存储作用域：`session` (各会话独立) 或 `global` (全局所有会话共用同一生活线) |

---

## 数据持久化

所有数据严格遵循 AstrBot 隔离原则，保存在：
`data/plugin_data/astrbot_plugin_life_memory/`

文件读写使用原子替换（`.tmp` + replace）及全面的容错降级保护，确保主链路稳固不崩溃。
